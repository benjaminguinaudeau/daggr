# daggr: Quick DAG Diagrams with Sensible Defaults

Wraps 'ggdiagram' and 'ggarrow' with opinionated defaults for drawing
directed acyclic graphs (DAGs). Provides styled node constructors, a
connection helper, and a clean theme so that 'library(daggr)' replaces
~30 lines of boilerplate setup.
